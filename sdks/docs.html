Quick Start

Python

bashpip install kaf-extract
pythonfrom kaf_extract import KafExtract

client = KafExtract(api_key="kaf_your_key")
result = client.extract_sync("https://books.toscrape.com", fields=[
    {"name": "title", "selector": "h1", "type": "text"},
    {"name": "price", "selector": ".price_color", "type": "text"},
])
print(result.data["title"])  # "A Light in the Attic"

API Reference

Base URL: https://extract.kafcenter.com
Auth: X-API-Key header for extraction endpoints. Authorization: Bearer <JWT> for user endpoints.

Extraction

POST/api/v1/extract

Extract structured data from a URL. Supports text, html, attribute, exists, markdown, screenshot, and ai types. Redis-cached with 5-min TTL. Use ?async=true for async jobs.

POST/api/v1/extract/ai

AI-powered extraction — no selectors needed. Uses Ollama (kimi-k2.6 or glm-5.1).

POST/api/v1/extract/batch

Extract from up to 50 URLs in parallel. Same schema applied to all.

GET/api/v1/extract/{job_id}

Poll for async extraction job results.

POST/api/v1/extract/screenshot

Capture screenshots — full page, viewport, or specific element.

Auth

POST/auth/register

Create an account. Returns JWT access + refresh tokens.

POST/auth/login

Login with email + password. Returns JWT tokens.

POST/auth/refresh

Exchange refresh token for new token pair.

GET/auth/me

Get current user profile.

PUT/auth/me/password

Change password.

Vouchers

POST/api/v1/vouchers/redeem

Redeem a voucher code for credits/subscription.

GET/api/v1/vouchers/history

View your redemption history.

System

GET/health

Health check: API, database, Redis status. No auth required.

GET/metrics

Usage metrics: requests, cache hits, latency, error rate.

Extraction Types

text

Inner text of the matched element.

html

Inner HTML of the matched element.

attribute

Value of a specific HTML attribute (e.g., src, href).

exists

Boolean: true if the selector matches anything.

markdown

Full page content as clean Markdown.

screenshot

Base64-encoded PNG screenshot of the matched element.

ai

LLM-powered extraction via Ollama. No selectors needed.

Rate Limits

All extraction endpoints enforce per-API-key sliding window rate limits. Exceeding the limit returns HTTP 429.

Header Description
X-RateLimit-LimitMax requests per window
X-RateLimit-RemainingRequests remaining in current window
X-RateLimit-ResetUnix timestamp when the window resets
Retry-AfterSeconds until you can retry (only on 429)
